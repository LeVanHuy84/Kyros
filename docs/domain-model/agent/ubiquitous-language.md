# Ubiquitous Language — AI Agent Bounded Context

This document defines the core business terms and concepts within the **AI Agent Bounded Context** (Cognitive Orchestration) of the AI Executive Assistant. Standardizing these terms ensures clear communication between business analysts, domain experts, developers, and the AI Agent.

---

## Glossary of Terms

### 1. Goal
- **Definition**: A high-level request or objective submitted by the user in natural language.
- **Synonyms**: User Goal, Intent, Request.
- **Context-Specific Meaning**: Represents the starting point of the Agent execution. A Goal is decomposed into a structured Plan.

### 2. Plan
- **Definition**: A dependency-aware, ordered sequence of steps generated by the AI Agent to accomplish a Goal.
- **Synonyms**: Execution Plan, Sequence of Actions.
- **Context-Specific Meaning**: Each Plan is associated with a single Goal and is presented to the user for confirmation before any action is executed.

### 3. Plan Step
- **Definition**: A single, discrete action within a Plan that maps to a specific Tool invocation.
- **Synonyms**: Action, Plan Item.
- **Context-Specific Meaning**: Represents a single call to a domain capability (e.g. "Create task A", "Verify calendar event B").

### 4. Tool
- **Definition**: A registered, callable capability representing an internal domain operation or an external integration hook.
- **Synonyms**: Agent Capability, Function.
- **Context-Specific Meaning**: Tools are defined in the Tool Registry with specific parameter schemas, descriptions, and permissions. The AI can call them but cannot access database tables directly.

### 5. Tool Registry
- **Definition**: The centralized, secure catalog of all Tools that the AI Agent is authorized to invoke.
- **Synonyms**: Tool Directory, Capability Catalog.
- **Context-Specific Meaning**: Acts as the exclusive gateway for the Agent to interact with the system. No direct database access or service bypassing is allowed.

### 6. Reflection
- **Definition**: The process of evaluating the output and status of a Tool execution to determine if it succeeded or failed, and deciding on next steps.
- **Synonyms**: Self-Reflection, Error Checking.
- **Context-Specific Meaning**: Happens automatically after every tool invocation. It determines whether to continue the plan, trigger a re-plan, or escalate.

### 7. Re-planning
- **Definition**: The autonomous generation of a modified Plan in response to a step failure detected during Reflection.
- **Synonyms**: Plan Modification, Self-Correction.
- **Context-Specific Meaning**: Limited to a maximum of 3 automatic attempts per goal. If it fails further, it triggers an Escalation.

### 8. Escalation
- **Definition**: The action of halting execution and requesting manual user intervention when an unrecoverable tool error occurs or the re-planning limit is exceeded.
- **Synonyms**: Escalating, User Intervention Request.
- **Context-Specific Meaning**: Puts the session in an Escalated state, halting the planner loop and prompting the user with an error summary.

### 9. Approval Request
- **Definition**: A formal request submitted to the user to authorize the execution of a generated Plan or a sensitive action.
- **Synonyms**: Human-in-the-Loop Check, Approval.
- **Context-Specific Meaning**: A blocking checkpoint. The plan steps cannot begin until this request is resolved.

### 10. Resolution
- **Definition**: The user's decision to either **Approve** or **Reject** a pending Approval Request.
- **Synonyms**: Approval Decision, User Resolution.
- **Context-Specific Meaning**: Standardized values: `Approved` (allows execution to proceed) or `Rejected` (halts execution and prompts for plan adjustments).

### 11. Grounding
- **Definition**: The constraint ensuring that the Agent's reasoning and question-answering are strictly based on actual, retrieved facts.
- **Synonyms**: Context Grounding.
- **Context-Specific Meaning**: The Agent must cite at least one source document (notes or chat history) for every assertion. If no source is found, it must state "I do not know" rather than hallucinating.
